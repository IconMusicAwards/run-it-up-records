# Run It Up Records
Official showcase website for Run It Up Records.

## Editing content
Most recurring website content is controlled from `js/content.js`. Replace the placeholder names/text there and add image paths after uploading images into the appropriate `assets` folder.

Suggested folders:
- `assets/logos/`
- `assets/artists/`
- `assets/staff/`
- `assets/releases/`
- `assets/events/`
- `assets/gallery/`

## Official logo
Upload the official logo as `assets/logos/riu-logo.png`. Once present, the hero can be switched from the styled placeholder to the real logo.

## Hosting
Designed as a static GitHub Pages website with no paid server dependency.
